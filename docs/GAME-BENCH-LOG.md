# Игровые измерения

Канонический результат проекта — Cyberpunk 2077, 50 fps / 135 Вт при
`GFX_SPEED_SELECT=0x4`. Сравнивать прогоны можно только при одинаковых сцене,
разрешении, preset, RT, DLSS, версии игры и драйвере.

Игра сохраняет эти условия в `summary.json`; используйте:

```powershell
out\bench-game.ps1
out\bench-game.ps1 -Card '3070 Ti' -All
out\bench-game.ps1 -Card '3070 Ti' -NoRT -NoDLSS
```

По умолчанию скрипт фильтрует также объём RAM, потому что в каталоге могут быть
результаты нескольких машин с одинаковым spoofed GPU name. `-ShowDropped`
объясняет фильтрацию, `-AnyMachine` отключает её.

`summary.json` не содержит мощность и частоты; их записывают отдельным NVML/
HWiNFO замером во время того же прогона. Не объединяйте несинхронные источники.
Число кадров различается с FPS, потому что benchmark идёт по времени; отсутствие
`summary.json`/`frames.csv`, а не малое число кадров, указывает на обрыв.

Полная методика и таблица исходных прогонов:
[`history/GAME-BENCH-LOG.md`](history/GAME-BENCH-LOG.md).

# Исторический архив

Здесь сохранены полные рабочие журналы проекта до compaction 2026-10-11.
Они нужны для проверки происхождения выводов, отрицательных экспериментов,
отпечатков и аппаратных прогонов, но **не являются текущими инструкциями**.

Актуальные точки входа:

- [`../../README.md`](../../README.md) — установка и возможности;
- [`../STATUS.md`](../STATUS.md) — технический статус;
- [`../../BUILDING.md`](../../BUILDING.md) — сборка и приёмка;
- [`../../KNOWN-ISSUES.md`](../../KNOWN-ISSUES.md) — действующие ограничения;
- [`../../out/BUILDS.md`](../../out/BUILDS.md) — компактный реестр сборок.

исследования; поздний вывод не переписывает ранний. Для принятия решений всегда

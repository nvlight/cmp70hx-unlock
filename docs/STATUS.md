# Технический статус CMP 70HX Unlock

Актуально на 2026-10-11. Это каноническая техническая сводка; подробная
хронология сохранена в [`history/`](history/README.md).

## Что работает

| Область | Результат | Проверка |
|---|---|---|
| Compute | потолок issue-rate 1/32 снят, `pp512` ×11,25 | llama-bench, повторные прогоны |
| Render | `GFX_SPEED_SELECT=0x4`, Cyberpunk 2077 50 fps / 135 Вт | игровой бенчмарк и аппаратные логи |
| Частота | 1545 МГц под нагрузкой, без троттлинга | NVML/HWiNFO |
| Память | 8 ГБ, 256 бит, около 608 ГБ/с | CUDA properties и бенчмарки |
| Запуск | около 4,9 с вместо 218,1 с | `TIME ... final` и внешний замер |

Анлок выполняется UEFI-приложением до Windows. Через защищённую загрузку SEC2
открываются WPR2/PLM, затем выставляются SS0/SS1 и две необходимые render-маски.
После FLR управление возвращается прошивке, и Windows загружается без POST.

## Границы результата

- Карта сообщает 30 SM / 3840 CUDA cores; анлок это число не меняет.
- `FEAT_READOUT_0.PGRAPH` остаётся выключенным. Доступными EFI-рычагами это не
  снимается; графика поэтому быстрее стока, но не становится полной RTX 3070 Ti.
- Для игр нужен драйвер с разрешённым render-путём для CMP, например
  `dartraiden/NVIDIA-patcher`.
- Анлок волатилен: после POST его нужно выполнить снова.
- Поддерживается только CMP 70HX GA104 8 ГБ, PCI ID `10de:248a`.

## PCIe Gen2

Серия E-A…E-P закрыла доступный путь отрицательно. Привилегированный V67 writer
работает, нужные маски и policy-регистры открываются, TLS=2 подтверждается на
обоих концах, Retrain Link запускается, но физический линк остаётся Gen1 x4.
Повтор по последовательности внешнего референса дал тот же результат.

Это не означает, что Gen2 физически невозможен; это означает, что доступные
этому проекту UEFI/BAR0/PCI-config способы исчерпаны. Повторять свипы масок,
Host2Jtag, LC2 mirror или серии retrain без нового механизма не следует.

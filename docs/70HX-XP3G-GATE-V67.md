# PCIe Gen2: серия XP3G/V67

Серия E-A…E-P завершена. V67 privileged writer открыл доступные гейты,
policy-регистры приняли целевые значения, TLS=2 подтвердился на GPU и bridge,
а retrain выполнялся по нескольким последовательностям. Во всех случаях
физический линк остался Gen1 x4.

Текущий вердикт находится в [`STATUS.md`](STATUS.md). Полный журнал серии,
включая MD5 и строки аппаратных логов, сохранён в
[`history/70HX-XP3G-GATE-V67.md`](history/70HX-XP3G-GATE-V67.md).

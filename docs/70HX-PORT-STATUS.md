# Статус порта CMP 70HX

Актуальная компактная сводка перенесена в [`STATUS.md`](STATUS.md).

Коротко: compute ×11,25, render 50 fps / 135 Вт, запуск около 4,9 с, 30 SM без
расширения и PCIe Gen1 x4 после исчерпывающей серии Gen2 E-A…E-P. Слово
«частичный» больше не выводится из `FEAT_READOUT_0.bit8`: этот признак оказался
недостоверным. Полнота доступного GR проверяется отдельной A/B-матрицей драйвера.

Полная хронология порта и исходные выводы по этапам сохранены в
[`history/70HX-PORT-STATUS.md`](history/70HX-PORT-STATUS.md).

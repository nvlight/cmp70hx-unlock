# Итог проекта CMP 70HX

Compute разблокирован в ×11,25 по `pp512`; render работает с
`GFX_SPEED_SELECT=0x4` и даёт 50 fps / 135 Вт в зафиксированном тесте. Карта
остаётся на 30 SM, а PCIe — Gen1 x4. Текущий полный итог находится в
[`STATUS.md`](STATUS.md).

Сводка состояния на 2026-09-29 сохранена без переписывания в
[`history/70HX-FINAL-SUMMARY.md`](history/70HX-FINAL-SUMMARY.md).
